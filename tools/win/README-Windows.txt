BARLINE FOR WINDOWS (10 and 11)

START
  Unzip this folder anywhere you like (Documents is fine) and keep it together: barline.exe finds
  its drum kits in the kits folder beside it.
  Double-click barline.exe: Barline opens in its own window (Microsoft Edge's app window).
  Closing that window quits Barline.

  The first time, Windows may say "Windows protected your PC" (Barline isn't from the Microsoft
  Store): click More info, then Run anyway. When Windows asks to let Barline on the network,
  allow Private networks, so your iPad or phone can reach it.

THE LOOPER PEDAL
  Plug it in with USB. Windows 10 (version 1703 or later) and 11 have the USB audio driver it needs.
  On the pedal (hold the encoder for the menu): MIDI > Source USB, Clock On, Ext Ctrl On.
  Windows lets one program at a time use a MIDI port: close other music software first.

THE TERMINAL SCREEN
  In Windows Terminal, open this folder and type:  .\barline      (or .\barline doctor to check
  the setup). Everything else is in GUIDE.txt; where it says ~/.local/share/barline, on Windows
  your songs and settings are in %APPDATA%\Barline.
